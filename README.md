# UKSSSC Kanishth Sahayak / Junior Assistant Preparation Website

## Included
- PYQ-oriented dashboard
- Analysis of the supplied ZIP inventory
- Topic priority map
- Hindi / Uttarakhand GK / Reasoning / Maths / Computer / Polity / History / Science practice
- 20/30/40-question random mock
- 30-minute timer
- +1 correct, -0.25 wrong
- Subject-wise result and weak-area review
- Dark mode
- Works as a static HTML/CSS/JS website; no server required

## Run
Open `index.html` directly in Chrome/Edge, or use VS Code Live Server.

## Important
The ZIP contains 5 PDFs, including a duplicate 2016 Junior Assistant paper. Several PDFs are scan/image based, so OCR wording can contain recognition errors. Questions marked `PYQ` are derived from the supplied papers/pattern analysis; `Practice` questions are newly authored practice questions based on those observed topics.

The website is a preparation tool, not an official UKSSSC portal. Always verify the latest official notification for the final syllabus, written pattern, typing/shorthand requirements, dates and eligibility.
